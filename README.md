# Campaign ROI Estimation

Full-stack application for estimating marketing campaign return on investment using a trained machine-learning model.

## Project structure

- `backend/`: FastAPI application, database access, services, and tests
- `frontend/`: Vite and React user interface
- `ml/`: model training, evaluation, prediction code, and saved artifacts
- `data/`: source and processed campaign datasets

See `frontend/README.md` for frontend setup. Configure the backend using `backend/.env.example`.
